# Maidana Servicio Técnico — web personalizada

Landing estática en español argentino para **Maidana Servicio Técnico**, en Posadas, Misiones.

## Contenido

- Presentación breve con el logo y los colores compartidos por el profesional.
- Seis áreas de servicio con aclaraciones de matrícula según la información recibida.
- Galería con las diez fotos del profesional, alojadas localmente y optimizadas en WebP.
- Consultas directas a WhatsApp y navegación adaptada a móvil.
- La primera versión conserva `noindex` mientras se revisa con el lead.

## Publicación

Archivos estáticos desde la raíz de `main`. URL: https://tuwebentresdias.github.io/servicio-tecnico/.
